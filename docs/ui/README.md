# 画面UI（v1）

`mockups/` の静的HTMLは、画面の構成と見た目の方向を示す見本。1ファイル1画面で、窓の基準は 1440×900（最小 1024×700）。ブラウザで `mockups/index.html` を開くと、左端のバーから画面間を移動できる。

見本は実装用のコードではない。Reactで作るときは、構成と `tokens.md` の値を使い、部品は作り直す。

| 資料 | 中身 |
| --- | --- |
| `tokens.md` | デザイントークン（色・書体・文字の大きさ・間隔・角丸・部品の高さ・骨格の寸法）。v0 からの差分付き |
| `decisions-v1.md` | v1 で決めたこと（骨格、AIの様子の置き場所、狭い窓、部品を減らした方針、画面ごとの直し） |
| `mockups/scn-ui.css` | トークンの値の正。部品のクラスは見本 |
| `mockups/*.html` | 画面の見本 |

## 骨格（要約）

| 部位 | 内容 | 大きさ |
| --- | --- | --- |
| タイトルバー | 左：作品メニュー・ブランチ／中央：検索とコマンド／右：AIの様子・再生・右の欄の開け閉め | 高さ 44 |
| 左端のバー | 企画・本文・フロー・設定・素材・変数・検証・AI・出力、下に離して環境設定 | 幅 64（項目 56×48） |
| 一覧 | 画面ごとの一覧（シーン、型、名前空間、タスクなど） | 幅 248（狭いと 220） |
| 作業領域 | 画面の主役。上に見出しの帯 | 残り（1440 で 828） |
| 右の欄 | 選んでいるものの詳細 | 幅 300（1280 より狭いと閉じ、開くと 320 で重ねる） |
| ステータスバー | 左：画面ごと／右：保存の様子・問題の数・形式 | 高さ 28 |

詳しくは `decisions-v1.md` の U01〜U06。

## このリポジトリでの扱い

- v1 の決めごとのうち、実装で変えたこと（自動保存はしない、AI の接続先は名前付きのまま、W606 の意味、今は無い機能は作らない）は `decisions-v1.md` の「実装で見本と変えること」（`docs/decisions.md` の D086）。
- 点検の記録は `audit.md`（T4-11）、デザインキャンバスへの頼みは `design-brief.md`（T4-15）。v0 の見本とトークン表は Git の履歴にある。
