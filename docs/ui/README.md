# 画面UIの大枠

`mockups/` の静的HTMLは、画面の構成と見た目の方向を示す見本。幅1440×高さ900を想定している。ブラウザで `mockups/index.html` を開くと、左端のバーから画面間を移動できる。

見本は実装用のコードではない。Reactで作るときは、構成と下のデザイントークンを参考にし、部品は作り直す。フェーズ0（T0-7）で使うのはデザイントークンと、エディタ・シーン一覧・グラフの大まかな配置だけ。

## 画面の一覧

| ファイル | 画面 | 主な要素 | 作るフェーズ |
| --- | --- | --- | --- |
| `01-ideas.html` | 企画とアイデアメモ | メモのボード（未整理・採用・保留、昇格の操作）、企画書のフォーム、AIの問い返し | 2 |
| `02-editor.html` | 本文エディタ（執筆表示） | シーン一覧、演出のチップ表示、選択肢と分岐のカード、編集中の行だけ記法を表示、右に登場キャラ・変数・素材・問題・AIの指摘 | 1（土台は0） |
| `02b-editor-source.html` | 本文エディタ（ソース表示） | 生のテキスト、行番号、行ID、構文の色分け | 0〜1 |
| `03-flow.html` | 構造グラフ | 粒度の切り替え（ルート・章・シーン）、ルートの帯、スタブ、AI下書き、AIの提案ノード、選択中シーンの出入口と変数 | 1（土台は0） |
| `04-bible.html` | 設定DB | 型の一覧と項目の定義、エントリ一覧、型から作るフォーム、逆引き | 1 |
| `05-assets.html` | 素材カタログ | 素材の一覧（仮素材・未登録）、キャラ×差分の表、発注リスト | 2 |
| `06-preview.html` | プレビュー（ADV） | 背景・立ち絵・テキストウィンドウ、デバッグ（変数の編集、ジャンプ、選択肢の自動選択、バックログ） | 1 |
| `06b-preview-vertical.html` | プレビュー（縦書き） | ルートを選んで通読、選択肢の注記、ルビ・傍点・縦中横 | 2 |
| `07-ai.html` | AI実行 | 段階ごとのタスク一覧、自律実行の進み具合、生成したシーンと点検結果、ブランチからの取り込み、実行の設定 | 3 |

環境設定（左端のバーの「環境設定」）にはモックが無い。AIの接続先（T3-5、D066）は、出力の画面と同じカードの並びで、接続先ごとに使う URL とモデル、この端末での上書き、キー、クラウドの許可、「接続を試す」を置く。タイトルバーの接続先は、モック `07-ai.html` の「AI：Ollama（ローカル）」に合わせ、印を形（● × … ○ ！）でも分ける。

## 画面の骨格

すべての画面で、次の骨格を共有する。

| 部位 | 内容 | 目安の大きさ |
| --- | --- | --- |
| タイトルバー | 作品名、ブランチ、コマンドパレット、AIの接続先、再生ボタン | 高さ44px |
| 左端のバー | 企画・本文・フロー・設定・素材・変数・検証・AI・出力・環境設定 | 幅64px |
| 一覧パネル | 画面ごとの一覧（シーン、型、タスクなど） | 幅220〜270px |
| 作業領域 | 画面の主役 | 残り |
| 文脈パネル | 選択中のものの詳細 | 幅260〜320px |
| ステータスバー | 表示モード、文字数、問題の数、形式のバージョン | 高さ28px |

幅が足りないときは、文脈パネル、一覧パネルの順に下へ回り込む。

### 色の意味

- 藍色（accent）：選択、主要な操作、話者、ユーザーが書いた構造（選択肢・分岐）
- 緑青（ai）：AIに関わるもの。AI下書き、提案ノード、AIの実行と出自
- 琥珀（warn）：警告と仮素材
- 灰色の点線：スタブ（本文の無いシーン）

色だけで区別しない。スタブは点線、提案ノードは緑青の点線、AI下書きは緑青の実線、と線の種類も変える。

### 文字

| 用途 | 書体 | 大きさ |
| --- | --- | --- |
| UI | Zen Kaku Gothic New | 13px（ラベルは12px、最小11px） |
| 本文（執筆表示、縦書き） | Shippori Mincho | 17px、行の高さ1.95 |
| 記法、ID、式 | JetBrains Mono | 12〜13.5px |

書体はGoogle Fontsで配布されている。アプリには同梱するか、OSの書体（游ゴシック、ヒラギノ、游明朝など）に置き換える。

### 形

- 角丸：入力欄とボタンは6px、カードは10px、パネル内の項目は8px。
- 影とグラデーションは使わない。面の色と線で区切る。
- 押せる部品の高さは、28〜36pxを目安にする（デスクトップアプリのため）。

## 元のデザインの出所
