放課後の屋上

「やっと来た。遅いよ」

　風が強くて、灯の髪が乱みだれていた。

「あのね、話があるんだ」

　灯は16時のチャイムが鳴り終わるまで、何も言わなかった。

〔選択：黙ってうなずく〕

「……そういうところ、ずるいよね。昔からずっとそうだった。言わなくても分かってくれるって、私が勝手に思ってるだけなのに。だから今日も、言えないまま来ちゃった」

　それでも、彼女は笑っていた。
