登校

　坂道の途中で、後ろから鞄がぶつかってきた。

「おはよ、湊。今日も眠そうだね」

　眠そうなのはお互いさまだ、と言いかけて、やめた。笑う顔に、昨日までと違うところは見つからなかった。

昼休みの教室

「湊くん。灯ちゃん、最近なにか言ってた？」

「なにかって？」

「……ううん、なんでもない」

　五限の予鈴が鳴った。机の中に、二つ折りのメモが入っていた。

　放課後、屋上で。丸い字は、灯のものだった。
