## 2. 色の意味と線

同じ色でも、線の種類・印・言葉で必ず区別する。色だけで伝えない。

| 意味 | 色 | 線 | 印・言葉 |
| --- | --- | --- | --- |
| 選択・人の書いた構造（選択肢・分岐・話者・ジャンプ） | 藍 | 実線 | 選んでいる行は太字にもする |
| AIの生成物・提案・実行・出自 | 緑青 | 下書きは実線、未採用の提案は点線 | 「AI」の札、✦ の印 |
| 警告 | 琥珀 | 実線 | ⚠ の印 |
| 仮素材（ファイルの無い素材） | 琥珀 | 点線 | 「仮素材」の札 |
| スタブ（本文の無いシーン） | 灰色 | 点線 | 「スタブ」の札、点線の○ |
| エラー・保存の失敗・取り消せない操作 | 赤 | 実線 | ⊗ の印、言葉 |

- 点線を使うのは、スタブ・仮素材・未採用のAI提案の3つだけ。注意の帯や区切りには点線を使わない。
- 差分（マージ）に赤と緑は使わない。選んだ側を藍の薄い面と、ラジオボタンの言葉で示す。
- シーンの状態の印は形で分ける：執筆中＝藍の●、下書き＝○、完成＝灰色の●、スタブ＝点線の○、AI下書き＝「AI」の札。

## 4. 書体

OSに入っている書体だけを使う。Webフォントは同梱しない。

| トークン | 値 | 使う場所 |
| --- | --- | --- |
| `--font-ui` | `"Hiragino Sans","Hiragino Kaku Gothic ProN","Yu Gothic UI","Meiryo UI",sans-serif` | UIのすべて |
| `--font-text` | `"Hiragino Mincho ProN","YuMincho","Yu Mincho",serif` | 作品の文章だけ（執筆表示の本文、縦書き、エントリ名、シーン見出し、メモ） |
| `--font-mono` | `ui-monospace,Menlo,Consolas,"Hiragino Sans","Yu Gothic UI",monospace` | ソース表示、ID、式、パス |

- Windows のゴシックは「Yu Gothic UI」を指定する（「Yu Gothic」は細く、かすれて見える）。
- 等幅の和文は、等幅書体に和文が無いので UI のゴシックに落ちる。ソース表示の桁そろえは半角だけで考える。
- v0 の Zen Kaku Gothic New・Shippori Mincho・JetBrains Mono は**削除**。

押せる部品は 28〜36px。v1 では **32 と 28 の2つだけ**にした。

| トークン | 値 | 部品 |
| --- | --- | --- |
| `--h-control` | 32 | ボタン（主・副・危険）、入力欄、選択欄、分割の切り替え |

## 11. 実装に写すとき

- `mockups/scn-ui.css` の `:root` をそのまま `app/src/styles/tokens.css` に写す。部品のクラスは見本なので写さず、Reactの部品として作り直す。
- フェーズ0（T0-7）で使うのは、色・書体・文字の大きさ・骨格の寸法だけ。
- 狭い窓の切り替えは、窓の幅 1280 を境にする（`@media (max-width:1279px)`）。
- プレビューの舞台（`.stage`・`.msgwin`・`.namebox`）の色は、作品側の見た目の仮置きなのでトークンにしない。
- 主のボタンの上の白い文字（`#FFFFFF`）はトークンにしない。
