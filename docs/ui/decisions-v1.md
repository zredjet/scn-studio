# 画面の見た目 v1 で決めたこと

実装したアプリの点検（2026-10-09、画面の写し 16枚）と、キャンバス「ADV執筆ツール 画面UI」の v0 モックを比べて決めた。見本は `mockups/`、値は `tokens.md`。

番号は `U` で始める（`docs/decisions.md` の `D` とは別の通し番号）。変えるときは人に確認し、ここを直す。

---

## 守ること（前提）

- 色の意味：藍＝選択と人の書いた構造、緑青＝AI、琥珀＝警告と仮素材、灰色の点線＝スタブ。色だけで区別しない。
- 書体は OS のもの（ヒラギノ・游）。影とグラデーションは使わない。明るい外観だけ。
- 押せる部品は 28〜36px、文字は最小 11px。窓の基準は 1440×900。
- 本文の執筆表示は「ソースの1行を1行に飾る」形のまま。

## 骨格

### U01 骨格の寸法を固定する

- 決定：タイトルバー 44・左端のバー 64・一覧 248・右の欄 300・ステータスバー 28（＋線 1）。作業領域は残り（1440 で 828）。作業領域の見出しの帯は 48（2段のときは 64）。
- 理由：v0 は一覧 220〜270、右の欄 260〜320 と幅で書いていたため、実装で画面ごとに幅がばらついた。
- 影響：一覧・右の欄の中身は、この幅で折り返す前提で作る。

### U02 タイトルバーの並び

- 決定：左から「作品メニュー（作品名）・ブランチ」｜中央「検索とコマンド（⌘K）」｜右「AIの様子・再生（分割ボタン）・右の欄の開け閉め」。
- 決定：**最近開いた作品・開く…（⌘O）・新しく作る…（⌘N）・フォルダを表示・この作品の設定**は、作品名を押して出る作品メニュー（幅 320）にまとめる。起動直後に作品が無いときは、作業領域に同じ3つを並べた「始める」画面を出す（見本なし）。
- 理由：Windows にはメニューバーが無く、macOS のメニューだけに置くと入口が OS で変わる。作品の出入りは頻度が低いので、1か所にたたむ。
- 再生：本文ではカーソルの位置から、フローでは選んだシーンから、ほかの画面では最初から。▾で始め方（最初から・このシーンから・セーブから）を選ぶ。
- 見本：`00-components.html` の 1、`12-overlays.html` の 1。

### U03 AIの接続の様子はタイトルバーの1か所だけで示す

- 決定：タイトルバー右の「AIの様子」だけが接続を言葉で示す。ローカルとクラウドを並べ、印の形で区別する（● 接続中・○ つながらない・鍵 送ることを未許可）。実行中は「実行中 1」と回る印を前に足し、左端のバーの「AI」にも点を付ける。
- 決定：押すとポップオーバー（幅 320）で、接続先・モデル・応答の速さ、クラウドの「許可する…」、AI実行と環境設定への入口を出す。
- 決定：ほかの画面には接続の注意の帯を出さない。使えない AI の操作は「押せない状態」と鍵の印、指を乗せたときの説明（「クラウドへ送ることを許可していません（タイトルバーのAIから）」）だけで示す。
- 理由：実装では各画面に接続の帯や「未接続」の文言が散らばり、同じことを何度も読ませていた。
- 見本：`00-components.html` の「AIの様子」、`12-overlays.html` の 1。

### U04 左端のバー

- 決定：上から 企画・本文・フロー・設定・素材・変数・検証・AI・出力。**環境設定は線で区切って一番下**に離す。プレビューは本文と再生ボタンから開く表示で、左端のバーには置かない（閉じると本文へ戻る）。
- 決定：項目は 56×48 で、アイコン 18 と名前 11 を縦に積む。選んでいる画面は面を明るくし、左に藍の線を付ける。
- 決定：検証には件数の札（警告だけなら琥珀、エラーがあれば赤）。AIには実行中の点（緑青）。
- 理由：アイコンだけでは「設定」と「環境設定」を取り違えやすい。名前を常に出す。

### U05 ステータスバー

- 決定：左は画面ごとの情報、右は全画面で共通（保存の様子・問題の数・形式のバージョン）。問題の数を押すと検証を開く。

| 画面 | 左に出すもの |
| --- | --- |
| 企画 | メモの枚数（状態ごと）・エンディングの数（本文に無いもの） |
| 本文 | 表示モード・シーンと字数・行と列・章の字数 |
| フロー | 粒度・シーンの数（スタブ・AI下書き）・選んでいるもの |
| 設定 | 今の型と数・型とエントリの数・参照切れ |
| 素材 | ファイルあり・仮素材・未登録・見張っているフォルダ |
| プレビュー | 位置（シーン・行ID・何行目）・画面とウィンドウの大きさ |
| 変数 | 変数の数・書いて読まない数・使っていない数 |
| 検証 | 最後に調べた時刻・段階2の様子・件数 |
| AI実行 | 実行中の数・取り込み待ち・履歴の数 |
| 出力 | 最後の書き出し |
| 環境設定 | 設定の保存先 |

- 1280 より狭いときは「形式」と章の字数を隠す。

### U06 狭い窓（最小 1024×700）

- 決定：幅 1280 以上は右の欄を出す。1280 より狭いと、右の欄を閉じて始め、一覧を 220 に縮める。
- 決定：閉じた右の欄は、タイトルバー右端のボタン（⌥⌘B）で開き、作業領域の上に幅 320 で重ねる。後ろは暗くしない。Esc・外を押す・もう一度ボタン・画面の移動で閉じる。
- 決定：重ねるので、開け閉めで本文の折り返しは動かない。
- 決定：1280 より狭いとき、ブランチ名は印だけにし、検索欄を 160〜280 に縮める。
- 理由：作業領域を 740 より狭くしないため（本文 16px で 1行 40字前後を保つ）。
- 見本：`13-narrow.html`。

## 部品

### U07 部品の種類を減らす

- ボタン：**主・副・小・危険・リンク風**の5種とアイコンだけ。高さは 32（標準）と 28（小）の2つ。主は1つの画面・ダイアログに1つまで。危険は塗りつぶさず、赤の線と文字。AIの操作は副に緑青の ✦ を付ける（緑青で塗ったボタンは作らない）。
- 札：1つの形（高さ 20・角 4）に意味ごとの色と線。押せる絞り込みだけ丸い札（chip、高さ 28）。
- カード：1つの形（角 8・線 1）。選んでいる＝藍の線と薄い面、AI下書き＝緑青の面、未採用のAI提案＝緑青の点線、スタブ＝灰色の点線。
- 注意の帯：画面の状態を知らせるときだけ。1つの区画に1本まで、線は実線。種類は ふつう（藍）・警告・エラー・AI の4つ。
- 理由：v0 と実装に、塗りの緑青ボタン、角 10 のカード、文字色 5段などが混ざり、同じ意味に複数の見た目があった。
- 見本：`00-components.html` の 4〜9。

### U08 保存の様子は4つ

- 決定：**保存中…／保存済み／保存していない変更／保存できません**。ステータスバーの右に出す（本文を複数開くようになったらタブにも）。書いてから1秒で自動保存。
- 決定：「保存していない変更」は、自動保存を切っているときと、外の変更と食い違ったときだけ出る。「保存できません」は赤で、押すと理由と再試行。
- 決定：閉じる・作品を切り替える・終えるときに保存していない変更があれば、確認のダイアログ（保存しない・キャンセル・保存する）を出す。

### U09 文字の段階は7つ、太さは2つ

- 決定：22・18・16・15・13・12・11 の7段、太さは 400 と 600。明朝は作品の文章（本文・シーン見出し・エントリ名・メモ）だけ、UI はゴシック。
- 決定：本文は 16/30（v0 は 17）。
- 理由：OS の明朝（ヒラギノ明朝・游明朝）は v0 の Shippori Mincho より字面が大きい。狭い窓で 1行の字数を確保する。

### U10 書体は OS のもの

- 決定：UI＝ヒラギノ角ゴシック／Yu Gothic UI（Meiryo UI に落とす）、作品の文章＝ヒラギノ明朝／游明朝、等幅＝ui-monospace／Menlo／Consolas。
- 決定：Windows では「Yu Gothic」ではなく「Yu Gothic UI」を指定する（細く、かすれて見えるため）。
- 影響：Webフォントを同梱しない。等幅の和文は UI のゴシックに落ちる。

### U11 線の使い分け

- 決定：点線は **スタブ・仮素材・未採用のAI提案** の3つだけ。注意の帯や区切りは実線。
- 決定：マージの差分に赤と緑を使わない。選んだ側は藍の薄い面と、ラジオボタンの言葉で示す。
- 決定：シーンの状態の印は形で分ける（執筆中 ●藍・下書き ○・完成 ●灰・スタブ 点線の○・AI下書き「AI」の札）。

### U12 決まりの例外

- 左端のバーの項目は 56×48（アイコンと名前を縦に積むため、高さ 36 を超える）。
- ルビは 11px（最小の文字の大きさに合わせる）。
- 入力欄の中の札（呼び名など）は押せる部品にしない。Backspace で外し、押すと文字に戻して直せる。
- 文中のリンクも、押せる高さは 28 を確保する（リンク風のボタンにする）。

## 画面

### U13 本文（執筆表示とソース表示）

- 決定：執筆表示は「ソースの1行を1行に飾る」形のまま。1行の最大は 860 で、作業領域が狭ければその幅で折り返す。行の左の溝（40）に AI の出自・警告の印を出す。
- 決定：検索と置換の欄はソース表示の上に付ける（⌘F）。正規表現（.*）・本文だけ・範囲（このファイル・作品全体）を選べる。見つかった語が変数の一部なら、右の欄で「名前の変更（F2）」へ誘導し、置換で変数名を変えさせない。
- 見本：`02-editor.html`、`02b-editor-source.html`。

### U14 シーン一覧

- 決定：章ごとに折りたためる（章の行に件数とファイル名・字数）。シーンの行は「状態の印・名前・ルート名・ID」。
- 決定：選んでいるシーンの下に、アウトライン（演出・選択・分岐・出口）を入れ子で出す。行番号付きで、押すとその行へ移る。
- 決定：1280 より狭いときはルート名を隠し、状態の印と ID を残す。

### U15 フロー

- 決定：一覧を置かず、作業領域を広く使う。見出しの帯に 粒度（ルート・章・シーン）・ルートで絞る・条件を表示・スタブを足す・辺を足す・自動整列・拡大率。
- 決定：右の欄は、**何も選んでいないとき**「フローの概要」を出す：操作の手引き（ダブルクリックで本文を開く等）、数（シーン・スタブ・AI下書き・エンディング・開始）、ルートごとの数、構造の問題（W503・W701 と「選ぶ」）、スタブの一覧と AI で下書き、操作（ダブルクリック・ドラッグ）。選ぶと、そのシーンの出入口・変数・問題に替わる。

### U16 設定DB

- 決定：フォームの欄を2列にする（長い文章の欄だけ2列ぶち抜き）。
- 決定：**立ち絵の差分**（素材カタログの同じキャラの立ち絵。仮素材は琥珀の点線）と**紐づく変数**（名前空間がキャラIDの変数。書き・読みの数と問題）を、エントリのフォームの中に置く。
- 決定：右の欄は逆引き（登場シーン数・台詞数・初出、登場シーンの一覧、参照されている所）。

### U17 素材

- 決定：状態は3つ。カタログにありファイルもある＝「あり」、カタログにあるがファイルが無い（`{}`）＝**仮素材**（琥珀の点線）、本文で使っているがカタログに無い＝**未登録**（琥珀の実線と ⚠）。
- 決定：右の欄で選んだ素材の詳細、キャラ×差分の表、発注リストの書き出し。

### U18 出力

- 決定：カードを「制作に渡す」（**収録の台本**・Ren'Py・発注リスト・通読用テキスト）と「ほかの形」（EPUB・縦書きPDF・ティラノスクリプト・宴・IR）の2群に分け、**収録の台本を先頭**にする。
- 決定：説明はカード1枚に1行（15字前後）。形式（CSV・.rpy など）は題の横に小さく。前回の書き出しと、再収録の候補の数をカードの下に出す。
- 決定：選んだカードの設定は右の欄に出し、主のボタン（「台本を書き出す」）は右の欄の下に1つだけ置く。
- 見本：`10-export.html`。

### U19 新しく足した画面

- 変数（`08-variables.html`）：一覧は名前空間（すべて・flag・キャラ・周回）と問題（書いて読まない・使っていない・宣言されていない）で絞る。表は名前空間ごとにまとめ、書き・読みの数と問題の札。右の欄に定義、紐づくエントリ、書く場所・読む場所、検証の段階2で分かった取りうる値。
- 検証（`09-check.html`）：重さ（エラー・警告・情報）の札で絞り、種類ごと・ファイルごと・シーンごとにまとめる。行ごとに「フローで見る」などの行き先。右の欄に、選んだ問題の説明・該当の行・直し方・AI に聞く・この警告を出さない。段階1（保存のたび）と段階2（手で、または書き出しの前に）を分けて示す。
- 環境設定（`11-preferences.html`）：一覧を「このアプリ（すべての作品）」と「この作品（project.toml）」の2群に分ける。右の欄は持たない。AIの接続はここで詳しく設定し、タイトルバーの AI の様子から入れる。
- 重ね表示（`12-overlays.html`）：ポップオーバー（暗くしない）とダイアログ（後ろを暗くする）の2種。幅は 320・480・600・960 の4つ。本文に書き込む操作（スタブを足す・辺を足す・名前の変更）は、書き込まれる行をダイアログの中で見せてから実行する。マージは重なった所だけ選ばせ、重ならない変更は黙って取り込む。

### U20 AI実行

- 決定：一覧に AIタスク（関わり方ごと：自律・生成・提案・指摘）と実行の履歴。各タスクに使う AI（ローカル・クラウド）を出し、クラウドが未許可なら鍵の印で押せない。
- 決定：実行中の画面は 進み方（段階ごと）・書いたシーン・下端の操作（ブランチの差分を見る・main に取り込む・破棄）。点検と自分で直す段階が終わるまで「main に取り込む」は押せない。
- 決定：人が書いた行は書き換えない旨を、書いたシーンの表の下に常に出す。

## 決めていないこと（実装の前に確かめる）→ 決めた（2026-10-09、`docs/decisions.md` の D086）

1. タイトルバーは**自前で描く**。macOS は Tauri の重ねるタイトルバー（`titleBarStyle: "Overlay"`）で信号機のボタンを残し、左に 72px を空ける。Windows は枠を消し、最小化・最大化・閉じるのボタンと窓のドラッグを自前で作る。
2. 右の欄の開け閉めは**画面ごとに覚える**（見本どおり）。1280 以上に広げたら必ず出す。
3. 環境設定の保存先は**今のまま**（AI の接続は端末の `ai.toml`、表示の好みは localStorage、作品の設定は `project.toml`）。
4. プレビューを別ウィンドウで開いたときの同期は**今のまま**（本文のカーソルの位置を別ウィンドウへ送り、別ウィンドウの「エディタで表示」で本文へ移る）。

## 実装で見本と変えること（D086）

- **U08 の自動保存はしない**。保存のしかたは `docs/decisions.md` の D085（Z1）のまま（本文とソースは ⌘S、フォームと環境設定は欄を離れたとき）。保存の様子の4つの言葉と、ステータスバーの右に出すことは見本に合わせる。保存の確認のダイアログ（保存しない・キャンセル・保存する）も見本に合わせる。
- **AI の接続先は、今の名前付きの接続先のまま**（`project.toml` の `[ai.<名前>]`。D066）。タイトルバーの AI の様子とポップオーバー、環境設定は、見本の形で、接続先を名前ごとに並べる（「ローカル」「クラウド」の2つに固定しない）。
- **W606 は仕様の意味**（読むのに一度も書かない変数）。`08-variables.html` の「W606 使っていない」は見本の誤り。読みも書きもしない変数は診断を出さず、変数の画面の絞り込み（使っていない）だけで示す。
- **今は無い機能は、今回は作らない**。置き場所も作らない（押せない飾りも置かない）。作るかどうかは後で個別に決める（`docs/review-for-human.md` の N1〜）：作品全体の検索と「本文だけ」、「セーブから」の再生、Claude Code（CLI）の接続、ローカルのモデルを一覧から選ぶ、AI実行の一時停止、環境設定の新しい頁（一般・エディタ・外部エディタとGit・キーの割り当て・検証の規則など）、台本の書き出しの細かい指定（キャラで絞る・ボイス名の形・列・再収録の候補だけ）と書き出しの履歴・IR の書き出し・書き出しの前の段階2、警告を出さない・規則の強さ・AI に聞く、変数の取りうる値、選んだシーンの後ろにスタブを差し込む・条件つきの辺。
- **T4-19 の画面は、今ある機能だけで見本の並べ方にした**（変えたところ）。
  - 検証：行ごとの行き先は今ある移り先（本文で開く・企画を開く・設定で見る・変数で見る・素材で見る）。段階2は見出しの帯の「段階2を調べる」で走らせ、結果（カバレッジとエンディング）は一覧の下に出す。直し方の文はコードごとの表（`app/src/check/fixes.ts`）。
  - 出力：カードを選ぶと右の欄に今ある設定と「書き出す」を出す。右の欄を閉じていても、カードを選んだら右の欄を出す（書き出すボタンが右の欄にあるため）。
  - 環境設定：頁は「AIの接続」だけ。「この作品」の群は説明だけ。接続先のカードは名前ごと（見本の「使い分け」の表と「上限」の節は作らない）。
  - AI実行：見出しの帯・一覧・右の欄（実行の設定）は見本の形。真ん中は今ある表示（自律の進み具合と生成したシーンの表、AIのブランチ）のまま（進み方の段の表と下端の操作の帯は作らない）。
