# IMEテスト表（T0-8）

T0-7で作ったアプリを `samples/houkago` を開いた状態で起動し、本文エディタで確かめる。結果の欄に「合」「否」「−（対象外）」を書き、否のときは症状をメモ欄に書く。

## 対象の環境

| 記号 | OS | 日本語入力 |
| --- | --- | --- |
| W1 | Windows | Microsoft IME |
| W2 | Windows | Google日本語入力（使っていれば） |
| M1 | macOS | 標準の日本語入力 |
| M2 | macOS | Google日本語入力（使っていれば） |

W1とM1は必須。W2とM2は、普段使っている場合に行う。

## テスト項目

必須の欄が「必須」の項目が、ゲートの条件になる。

| No | 操作 | 期待する動き | 必須 | W1 | W2 | M1 | M2 | メモ |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 地の文を文節ごとに変換して確定する | 確定した文字だけが入り、文字が重複しない | 必須 | | | | | |
| 2 | 変換中にEnterで確定する | 改行が入らない | 必須 | | | | | |
| 3 | 確定後にEnterを押す | 改行が1つだけ入る | 必須 | | | | | |
| 4 | 変換中に矢印キーで文節を移動する | エディタのカーソルが動かず、文節が移動する | 必須 | | | | | |
| 5 | 変換中にBackspaceを押す | 未確定の文字だけが消える | 必須 | | | | | |
| 6 | 変換候補の一覧を出す | 候補の窓がカーソルの近くに出る | 必須 | | | | | |
| 7 | 長い文を入力している間（変換中） | 診断の下線やグラフが、未確定の文字で変わらない | 必須 | | | | | |
| 8 | 行頭で「灯」と変換して確定する | 確定前に補完の候補が出ない（補完がある場合） | 必須 | | | | | |
| 9 | 「を入力して確定する | 自動で」が補われる場合、確定後に1つだけ補われる | 必須 | | | | | |
| 10 | 全角空白で字下げして入力する | 全角空白が保たれ、半角に変わらない | 必須 | | | | | |
| 11 | 「｜乱《みだ》」を全角の縦棒で入力する | 文字が化けず、ルビとしてハイライトされる | 必須 | | | | | |
| 12 | 入力後に元に戻す（Undo）を押す | 確定単位で戻り、未確定の途中の状態が残らない | 必須 | | | | | |
| 13 | 確定済みの文字を再変換する | 再変換でき、結果が正しく置き換わる | 任意 | | | | | |

| 15 | 日本語で検索する（エディタの検索） | 該当箇所が見つかる | 任意 | | | | | |
| 16 | 絵文字を含む行を入力・削除する | 位置がずれず、診断の下線の位置も正しい | 必須 | | | | | |
