# サンプル作品「放課後の灯」

`.scn` 形式のほぼすべての要素を含む、パーサとアプリのテスト用の作品データ。設計検討書と画面モックの例と同じ内容にそろえてある。

## 構成

| ファイル | 内容 |
| --- | --- |
| `story/chapter01.scn` | 共通ルート。`s012` が選択肢・条件分岐・生コード・ルビ・ウェイトを含む |
| `story/chapter02.scn` | 灯ルート。AI下書き（`s021`）、スタブ（`s022`）、エンディング |
| `story/chapter03.scn` | 紬ルート。条件分岐だけのシーンとエンディング |
| `concept.md` / `style.md` | 企画書と文体 |
| `bible/` | 設定DB（キャラクター4人、組織、伏線） |
| `variables.yaml` | 変数の定義 |
| `assets/catalog.yaml` | 素材カタログ（実ファイルは同梱していない） |
| `export/renpy.yaml` | Ren'Py向けの出力プロファイル |
| `ai/` | AIタスクの定義と出自記録 |
| `ideas/` | アイデアメモ |
| `CLAUDE.template.md` | 作品フォルダに置くAIエージェント向け指示書のひな形（作品では `CLAUDE.md` にする） |

## 意図して残している診断

次の診断は、テストのためにわざと残している。これら以外のエラー（E）や警告（W）が出たら、パーサかサンプルのどちらかに問題がある。

| コード | 場所 | 理由 |
| --- | --- | --- |
| I302 行IDが無い | `s013b` の3行、`s021` の2行 | AIの下書きで、まだ行IDが付いていない |
| I403 カタログに無い意味名 | `s011` の `@SE チャイム`、`s040` の `@背景 駅/夕方` | 未登録の素材の例 |

フェーズ1以降の検証で出る予定のもの：

| 内容 | 場所 |
| --- | --- |
| 行き止まり（W503） | `s014`（スタブで出口が無い） |
| 企画書のエンディングが本文に無い（W701） | `true_end` |
| 表記ゆれ（「私」と一人称「わたし」） | `s012` の `^k3ff` |
| メッセージウィンドウのはみ出し（3行×24字） | `s012` の `^k3ff` |

## スタブのシーン

本文（台詞・地の文）の無いシーン：`s014`、`s022`、`s030`、`s060`、`s061`。
