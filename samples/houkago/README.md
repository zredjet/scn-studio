# サンプル作品「放課後の灯」

`.scn` 形式のほぼすべての要素を含む、パーサとアプリのテスト用の作品データ。設計検討書と画面モックの例と同じ内容にそろえてある。

## 構成

| ファイル | 内容 |
| --- | --- |
| `story/chapter01.scn` | 共通ルート。`s012` が選択肢・条件分岐・生コード・ルビ・ウェイト・心の声（『』）の台詞を含む |
| `story/chapter02.scn` | 灯ルート。AI下書き（`s021`）、スタブ（`s022`）、エンディング |
| `story/chapter03.scn` | 紬ルート。条件分岐だけのシーンとエンディング |

## 意図して残している診断

次の診断は、テストのためにわざと残している。これら以外のエラー（E）や警告（W）が出たら、パーサかサンプルのどちらかに問題がある。`scn check samples/houkago` で、ちょうどこれだけが出る（段階1の検証はT1-4から）。

| コード | 場所 | 理由 |
| --- | --- | --- |
| I302 行IDが無い | `s013b` の3行、`s021` の2行 | AIの下書きで、まだ行IDが付いていない |
| I403 カタログに無い意味名 | `s011` の `@SE チャイム`、`s040` の `@背景 駅/夕方` | 未登録の素材の例 |
| W203 メッセージウィンドウのはみ出し（3行×24字） | `s012` の `^k3ff` | 長すぎる台詞の例（4行になる） |
| W503 行き止まり | `s014` | スタブで、まだ出口が無い |
| W605 書き込むだけで読まれない変数 | `variables.yaml` の `flag.ルート` | どのルートに入ったかの記録。本文ではまだ読んでいない（トゥルーエンドの分岐で使う予定） |
| W605 書き込むだけで読まれない変数 | `variables.yaml` の `akari.転校済み` | 灯エンドで立てるが、読むのはまだ書いていないトゥルーエンド（W701 と同じく、書きかけの作品の例） |
| W701 企画書のエンディングが本文に無い | `concept.md` の `true_end` | トゥルーエンドをまだ書いていない |

検証の段階2（自動巡回。`scn check samples/houkago --stage 2`、T3-2）では、上に加えて、ちょうど次が出る（D063）。サンプルの選択肢と条件が、書きかけの作品の形をそのまま残しているため：

| コード | 場所 | 理由 |
| --- | --- | --- |
| W506 決して選べない選択肢 | `s012` の `^k3fe`（`勇気 >= 2`） | `勇気` を2まで上げる道が、まだ書かれていない。この選択肢の先のスタブ `s014` が W503 の例になっている |
| W509 条件と選択肢をどう選んでも着かないシーン | `s014` | 上の選択肢からしか着かない |
| W509 条件と選択肢をどう選んでも着かないシーン | `s061` | bad_end。`s030` の条件の枝からしか着かず、選択肢だけでは着かない（D050） |
